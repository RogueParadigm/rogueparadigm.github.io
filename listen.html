Offline speech recognition

Elys Listen

Add offline voice recognition to your Unreal game.

Turn microphone input into text on the player’s machine. Connect the result to your own gameplay, with no cloud service or runtime API key.

Documentation

Actual gameplay demo · Watch on YouTube

In your project

Three ways to use it.

01

Give players a voice

Use transcribed words as input for commands or dialogue in your own gameplay logic.

02

Show what was said

Display the result with the supplied subtitle and transcript widgets, or build your own UI.

03

Keep recognition local

Run speech recognition without an internet connection after a model has been installed.

What you get

Included with the plugin.

  • Offline speech recognition and microphone controls
  • Push-to-talk and automatic voice detection
  • Optional subtitle, history and control-panel widgets
  • Model manager, Blueprint examples and setup guides

Unreal Engine & availability

Unreal Engine 5.8 · Windows 64-bit

The plugin is complete and awaiting Fab publication. Speech recognition runs offline once a model is installed. Text generation and speech synthesis are separate products.

Getting started

Make it work in your project.

  1. After publication, install Elys Listen from Fab and enable it.
  2. Choose a speech model in the Elys Listen Model Manager.
  3. Start listening in Blueprint and connect the text result to your game.
