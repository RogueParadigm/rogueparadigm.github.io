Feature Gallery

These captures come from the included Unreal Engine 5.8 sample and its Blueprint assets.

Playable challenge stations​

Demo_ERP_TargetingAndInteraction now includes separate, reusable Blueprint stations for instant press, hold, multi-press, timed press, and timing-window interactions. Each station uses the same public descriptor contract while selecting a different challenge class.

Runtime targeting​

The sample continuously evaluates nearby candidates and presents the selected target through the bundled targeting UI.

Runtime interaction and hold challenge​

The interaction domain supplies the action label, contextual description, input hint, and challenge instruction to the world-space prompt.

Runtime multi-press prompt​

The dedicated multi-press station demonstrates that labels and instructions come from the interactable descriptor rather than from hard-coded widget text.

Blueprint input integration​

Enhanced Input starts and stops the interaction attempt through the public ERPInteraction component API.

Interactable gameplay response​

The sample actor reacts to the interaction event without coupling its gameplay response to the awareness pipeline.

Target eligibility​

Targetable actors expose their eligibility through the Blueprint interface and can replace this minimal sample rule with project-specific logic.

Instanced-mesh interaction​

The sample registers instanced geometry and demonstrates the setup used by the instanced-interaction and proxy-swap systems.

Included widget previews​

The following tightly cropped images are Unreal UMG Designer previews of the included widgets. Runtime data such as action labels, target descriptors, challenge progress, and health values is supplied by the plugin components.

The included Demo_ERP_WidgetGallery level also groups the main interaction, challenge, and targeting widgets into one capture-friendly view.
